3.1 Instalación SCADA

INTRODUCCIÓN
iFIX es una solución SCADA de gestión de la información en tiempo real, verificada y de gran calidad que además es abierta, flexible y escalable, y que incluye, potentes visualizaciones de última generación. También dispone de un motor de control fiable y un potente histórico integrado.

¿Por qué iFIX?
  • Con una instalación simple obtendrá el sistema SCADA con todas sus funcionalidades, muy simple de desarrollar y fácil de mantener.
  • Gestión y control de datos en tiempo real.
  • Conformidad con los estándares de la industria para mejorar la consistencia y calidad.
En el SCADA el alumno podrá operar una caldera simulada con acceso a los sistemas principales, equipos y dispositivos, así como monitorizar el progreso de la conducción que realice de la misma, mediante instrumentación, alarmas y tendencias.

Podrá realizar control analógico y secuencial pudiendo operar, en manual o en automatico, los elementos más representativos de una caldera pirotubular.

 

La instalación del software del sistema SCADA consistirá en seguir las indicaciones que aparecerán al insertar el CD del software o al ejecutar el ejecutable del aplicativo.

La instalación del software SCADA empezará introduciendo el CD “Proficy HMI/SCADA iFIX 5.5”. Si no se autoejecuta, ejecutar "InstallFrontEnd.exe".

La primera pantalla que aparece es un menú para que pueda elegirse el tipo de instalación a realizar:

 



Figura 36. Pantalla instalación.

Se pulsará sobre el icono “Install iFIX 5.5”. Esto hará que se ilumine esta opción tal y como aparece en la siguiente figura.

 



Figura 37. Icono instalación.

Seguidamente aparece una pantalla de confirmación de la instalación sobre la que se pulsará de forma afirmativa “SI”.

A continuación aparecerá una pantalla para intentar instalar un producto de la suite Proficy llamado ProficyHistorian que es una herramienta para guardar Históricos de forma masiva.

A esta pregunta y en este proyecto se pulsará que “SI” para poder continuar con la instalación. Si se pulsara ”NO” el setup saldría de la instalación.

 



Figura 38. ProficyHistorian.


A continuación el Setup de instalación comienza con el proceso.




Figura 39. Proceso de instalación.


A la siguiente pregunta se contestará de forma afirmativa, aceptando así los términos de licencia. Seguidamente ha de pulsarse sobre la instalación “Typical”.




Figura 40. Tipos de instalación.


El software debe ser instalado en esta ruta: C:\Archivos de Programa\Proficy\Proficy IFIX  
[Conviene tener en cuenta que no siempre la ruta que aparece por defecto es la correcta, pudiendo aparecer la siguiente  C:\Program Files(x86)\Proficy\Proficy iFX en la que sobra el (x86) y debe quitarse manualmente]. 





Figura 41. Selección ubicación de destino.


Una vez elegidas las primeras configuraciones, el sistema empezará de forma automática a instalar el software.




Figura 42. Instalación automática.
 

El Setup instalará todos los componentes necesarios para el correcto funcionamiento del sistema.



Figura 43. Setup.


En la pantalla se seleccionarán las siguientes opciones:

  • Nodename  ONECLK

  • NodeType  SCADA

  • Connectivity  Networked

La siguiente pantalla preguntará si se desean añadir nodos en la red de conectividad del SCADA a la que le diremos “Skip”.
 



Figura 44. Nodos.


Por último se incluirá al SCADA dentro de las reglas de los permisos del Firewall a lo que se responderá “SI”.

 



Figura 45. Permisos Firewall.


A continuación se instala un cliente del producto “Change Management” y algunos drivers de comunicaciones.
 

Si nos pregunta si queremos instalar Microsoft Visual Basic for Applications Update
- Decimos que sí
- Aceptamos los términos de la licencia
- Nos saldrá una cartel diciendo que ha sido instalado, y aceptamos

Después de instalar diferentes componentes necesarios para el correcto funcionamiento del sistema, se llega a la instalación del software “Proficy Historian” a lo que ha de responderse  “NO”.
 



Figura 46. Software Proficy Historian.

 

Se preguntará si queremos ver "Releases notes" y decimos que no.
El sistema finalizará la instalación reiniciando el sistema operativo. El software será instalado dentro de la ruta establecida al principio de la instalación.


PASOS PARA COMPLETAR LA INSTALACIÓN
 

INSTALACION DE LA LIBRERÍA GORGONA Y TIMER


El objetivo del presente documento es dar a conocer los pasos necesarios que deben realizarse para implementar las dlls desarrolladas para guardar ejercicios en XML.
 
Se deben seguir los siguientes pasos:

  • Pegar en ‘C:’ la carpeta 'Libreria' con todo su contenido. (Esta carpeta se puede encontrar en el  DVD Software Simulador Dinámico Caldera de Vapor: Libro Digital, Entorno 3D, SCADA).
  • Entrar en la carpeta una vez copiada en la raíz de C.
  • Botón derecho sobre el archivo 'registerGorgona' y ejecutar como administrador.
Pegar en ‘C el archivo data.xml. (Esta carpeta se puede encontrar en el DVD Software Simulador Dinámico Caldera de Vapor: Libro Digital, Entorno 3D, SCADA).
 

MODIFICACIÓN DE LAS RUTAS DE LAS TAREAS

Tras instalar el ‘ifix’ acceder al menú de configuración del SCADA. Para ello, pulsar ‘Inicio/Todos los programas/Proficy HMI SACDA – IFIX 5.5/System Configuration’

 


Una vez allí, pulsamos ‘Configure’ en el menú superior. En las opciones desplegables pulsamos’Task’

 




Todas las rutas que aparecen deben tener apuntar a ‘Program Files’ no a ‘Program Files(x86)’ si alguna de ellas tiene el ‘x86’ se debe modificar y pulsar el botón ‘Change’. Una vez cambiadas todas, pulsar ‘OK’  y más adelante ‘Yes’. (Ver secuencia en la figura).


 



Finalmente salimos pulsando la pestaña File y la opción Exit.  Aceptamos para salvar la configuración
