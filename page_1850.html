3.1.1 Instalación proyecto calderas pirotubulares
IMPORTANTE
Antes de empezar con el proceso, asegurarse que el sistema SCADA está completamente parado.
 

El procedimiento a seguir consta de los siguientes pasos:

  • Creamos una carpeta llamada Herramienta virtual en C:
    Copiamos la carpeta Calderas-SCADA que se encuentra en el DVD "Software Simulador Dinámico Calderas de Vapor. Libro Digital, Entorno 3D, SCADA" en la carpeta Herramienta virtual
  • Abrir el programa de restauración de copia de seguridad del sistema SCADA IFIX5.5. Este programa se llama "Backup And Restore Wizard" y se puede encontrar en Inicio\Proficy HMISCADA iFIX 5.5\Tools.



Figura 47. Ruta de acceso a "Backup And Restore Wizard".


  • Pulsamos botón derecho, y ejecutar como administrador.
  • Al  abrirlo aparecerá un menú que preguntará la acción a realizar. En nuestro caso, querremos recuperar una copia de seguridad. Se pulsará sobre el botón "Restore" y aparecerá un ayudante que guiará a través del proceso de restauración de la copia de seguridad. Seguidamente ha de elegirse el fichero del que se desea restaurar la copia. Pulsamos Browse.




Figura 48. Copia de seguridad.


Vamos a la carpeta c:\Herramienta virtual\Calderas-SCADA y elegimos el fichero CALDERAS_****.fbk
Una vez elegido el fichero se pulsará sobre el botón de “Siguiente” para continuar con el proceso de restauración de la copia. Es importante asegurarse de elegir un fichero, de lo contrario aparecerá un mensaje de error indicando que no se ha seleccionado ninguno.
  • A continuación aparecerá un menú con las opciones para restaurar:
    • Dejaremos el mismo fichero SCU.
      • Se restaurará por completo el sistema marcando en la ventana de Restore File Selection, la opción Restore the entire system.



Figura 49. Opciones restauración.


El resto de las opciones se dejarán tal y como están. Para finalizar con el proceso, se pulsará el botón de "Finish".

 

APARECERÁN MENSAJES PREGUNTANDO SI SE DESEA SOBRESCRIBIR ARCHIVOS. DEBERÁ PULSARSE EN TODAS “Yes To ALL” HASTA FINALIZAR.

Si nos sale un cartel que nos dice que es imposible reemplazar el actual fichero SCU, le  damos a Aceptar.
Al finalizar el proceso se pulsará el botón de “Close” y ya será posible empezara trabajar de forma normal con el sistema SCADA.
